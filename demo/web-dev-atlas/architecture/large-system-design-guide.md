# Large-Scale Distributed Systems Reference

## Section 1: Replication Pattern #1

In distributed architectures, **replication** (iteration 1) balances latency, consistency, and fault tolerance across nodes.
- **Write path 1:** Validate payloads, enforce idempotency, and persist state before acknowledging callers.
- **Read path 1:** Serve from local caches when fresh; fall back to read replicas or primary storage on miss.
- **Failure mode 1:** Isolate downstream timeouts and rate limits so degraded dependencies do not cascade.
